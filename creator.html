About the project

ArchinthAI focuses on floor wise room planning, automated layout generation, view consistent 2D plans, elevations, and 3D concept visualization in a single workflow.

Features

  • Automatic layout generation
  • Custom room addition
  • 2D / 3D / Elevation generation
  • Room inventory panel
